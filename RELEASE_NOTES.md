## MediaFlow 0.5.0

- Detección de listas de reproducción y selección individual de videos antes de agregarlos a la cola.
- Vista de selección con títulos, duración y miniaturas cuando están disponibles.
- Nueva sección Música para convertir archivos de audio a MP3, FLAC, WAV, M4A, AAC, OGG y OPUS.
- Selección de bitrate para formatos compatibles y conservación de metadatos y portadas incrustadas cuando el formato lo permite.
- Se conserva la sección de conversión local de video y el mecanismo de actualización mediante GitHub Releases.

## MediaFlow 0.4.4

- Integración del actualizador mediante GitHub Releases.
- Aviso al usuario cuando hay una versión estable nueva.
- Descarga de instalador y comprobación SHA-256 antes de ejecutarlo.
- Conservación de carpetas de usuario y protección de procesos activos.
